# Спрятать панель: плагин Agents Hub

Кнопка со значком панели прячет и возвращает боковую панель хаба — как в Claude. Кнопка стоит в шапке панели, перед ☰; когда панель спрятана — у левого края страницы, на том же месте. Выбор помнится в этом браузере. На телефоне список сессий — отдельный экран, там кнопки нет.

## Для других плагинов

Плагин, которому нужно больше места (холст, редактор), прячет панель на время своего вида событием на `window`:

```js
// вошли в вид
dispatchEvent(new CustomEvent("hub-sidebar", { detail: { hide: true, by: "my-plugin" } }));
// ушли с вида
dispatchEvent(new CustomEvent("hub-sidebar", { detail: { hide: false, by: "my-plugin" } }));
```

`by` — имя плагина. Когда отпустили последнего, панель возвращается такой, какой её выбрал владелец руками. Нажал владелец кнопку, пока вид открыт, — это его выбор, он остаётся и после ухода с вида. Нет этого плагина — событие ничего не делает. Пока панель спрятана, у `<html>` есть класс `hs-hidden`, а в левом верхнем углу (32×32) стоит кнопка — оставьте там место.

## Поставить

«Настройки» → «Плагины» → вставить ссылку на этот репозиторий → «Проверить и поставить». Нужен хаб с Plugin API 1.5+ (место `sidebar.header`).
